Review `README.md` for product/setup/workflow, `ARCHITECTURE.md` for runtime/data flow, `SECURITY.md` for Auth/RLS/headers, and `js/README.md` or `css/README.md` for their respective code. Describe what exists on **this branch**. Mark future work and unverified remote Supabase/Vercel/GitHub settings explicitly. Do not copy redesigned-branch behavior into `main` docs until the corresponding code is merged. Check links, paths and commands before handing off; state which docs changed or why none were needed.
